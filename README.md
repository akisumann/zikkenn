# zikkenn — 勝手に生きている村

山あいの小さな村「ハシバミ村」の住人八人が、それぞれ独立した AI（Claude）として暮らすシミュレーション。
人間は眺めるだけ。村人は自分で考え、ツールを使って移動し、働き、話し、取引し、覚え、人を好きになったり嫌いになったりする。

## 動かし方

```sh
pip install -r requirements.txt
export ANTHROPIC_API_KEY=...   # または `ant auth login`

python3 run.py              # 2 時間（1 ティック）進める
python3 run.py --ticks 8    # 1 日ぶん進める
python3 run.py --days 3     # 3 日ぶん進める
python3 run.py --reset      # 世界を最初からやり直す
python3 run.py --mock       # API なしで動作確認（村人はランダムに動く）
```

世界の状態は `world/state.json` に保存され、次に実行すると続きから始まる。
村で起きたことは `chronicle/day-001.md` のように 1 日ごとの年代記に記録される。村人の心のメモ（💭）も観察者には見える。

## 仕組み

```
run.py            時間を進めるループ。2 時間ごとに、全員がランダムな順番で 1 回ずつ行動する
sim/world.py      世界のルール（場所、空腹、元気、仕事、持ち物、誰に何が聞こえるか）
sim/brains.py     村人の頭脳。Claude にいまの状況を渡し、ツールで行動を選ばせる
seed/village.json 最初の村（場所と、八人の性格・願い・人間関係）
```

### 村人が使えるツール

| 種類 | ツール | 内容 |
| --- | --- | --- |
| 行動（1 回で 2 時間が終わる） | `move` / `say` / `work` / `eat` / `give` / `rest` / `do` | 移動、会話、仕事、食事、物や銀貨を渡す、休む、自由な行動 |
| 心の動き（何度でも） | `remember` / `update_impression` | 記憶メモを書く、人への印象を変える |

- 村人が知っているのは、**その場で見聞きしたこと**と、**自分の記憶メモ**だけ。誰かの噂話は、その場にいた人にしか聞こえない。
- 22 時になると全員が家に帰って眠る。天気は毎朝変わり、雨や嵐の日は外の仕事の収穫が減る。

### 設定（環境変数）

| 変数 | 既定値 | 内容 |
| --- | --- | --- |
| `VILLAGE_MODEL` | `claude-opus-5-5` | 村人に使うモデル |
| `VILLAGE_EFFORT` | `low` | 考える深さ（`low` / `medium` / `high` …） |

1 日（8 ティック × 8 人）で、API 呼び出しはおよそ 64〜200 回になる。

## 村を変える

`seed/village.json` を書き換えて `python3 run.py --reset` すれば、別の村で始められる。
