# zikkenn — AI GM で遊ぶ TRPG

Claude Code に GM（ゲームマスター）をしてもらい、自分はプレイヤーとして TRPG を遊ぶためのリポジトリ。

## 遊び方

1. このリポジトリで Claude Code を起動する。
2. 話しかけるだけで始まる。
   - 「キャラを作りたい」→ 一緒にキャラクターを作る
   - 「セッションを始めたい」→ シナリオを選んで開始
   - 「今日はここまで」→ 進行状況を保存
   - 「続きから」→ 前回の続きから再開

GM の振る舞いは [`CLAUDE.md`](CLAUDE.md) に書かれている。

## 中身

```
CLAUDE.md            GM への指示
rules/core.md        オリジナル 2d6 ルール
tools/dice.py        ダイスローラー（全ロールを logs/dice.log に記録）
characters/          キャラクターシート
scenarios/           シナリオ（GM 専用・プレイヤーは読まない）
campaign/state.md    現在の進行状況
sessions/            セッションの記録
```

## ルール早見

- 判定：`2d6 + 能力値 + 技能(+2)` が目標値（易 7 / 普通 9 / 難 11 / 至難 13）以上で成功
- 6・6 はクリティカル、1・1 はファンブル
- 目標値まであと 1〜2 なら「代償付き成功」を選べる

詳しくは [`rules/core.md`](rules/core.md)。

## ダイスを手で振る

```sh
python3 tools/dice.py 2d6+2 --target 9 --label "鍵開け"
python3 tools/dice.py 1d6+1 --label "剣のダメージ"
```

## 同梱シナリオ

- **灯台守の消えた夜**（1〜2 人・1〜2 時間）：霧の漁村で、消えた灯台守を探すホラー寄りのミステリー。

※ シナリオファイルにはネタバレが含まれるので、プレイヤーとして遊ぶなら開かないこと。
