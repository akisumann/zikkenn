# zikkenn — 勝手に生きている村

山あいの小さな村「ハシバミ村」で、住人八人が勝手に暮らすシミュレーション。人間は眺めるだけ。
村人は「基本の行動ルール」に従って、働き、食べ、売り買いし、噂話をし、人を好きになったり嫌いになったりする。
`--ai` を付けると、村人ひとりひとりが Claude のエージェントになって自分で考えて動く。

## 動かし方

```sh
python3 run.py              # 2 時間（1 ティック）進める
python3 run.py --days 3     # 3 日ぶん進める
python3 run.py --reset      # 世界を最初からやり直す
python3 run.py --ai         # 村人を Claude で動かす（pip install anthropic と API キーが必要）
```

標準ではルールだけで動くので、Python 以外は何も要らない。
世界の状態は `world/state.json` に保存され、次に実行すると続きから始まる。
村で起きたことは `chronicle/day-001.md` のように 1 日ごとの年代記に記録される。村人の心の動き（💭）も観察者には見える。

## 基本の行動ルール（`sim/rules.py`）

村人は 2 時間ごとに、上から順に当てはまるものを 1 つ選んで行動する。

| 順 | ルール | 内容 |
| --- | --- | --- |
| 0 | 反応 | 物をもらったら印象が上がり、記憶に残す。自分の噂を聞いたら覚えておく（ターンは使わない） |
| 1 | 空腹 | 腹が減ったら食べる。なければ買う。金がなければ品物を売りに行くか、働いて稼ぐ |
| 2 | 疲労 | 疲れたら薬草を飲む。くたくたなら家に帰って休む |
| 3 | 食事時 | 朝・昼・夕は、少しでも腹が減っていれば食べる |
| 4 | 助け合い | 家族には手持ちから、好きな相手や頼んできた相手には余りから食べ物を分ける |
| 5 | 返事・おしゃべり | 話しかけられたら性格と好き嫌いに応じて返事をする。噂好きは聞いた話を広める |
| 6 | 商売 | 余った品を欲しがる人に売る。懐に余裕があれば酒場で一杯やり、人の品を買う |
| 7 | 習慣 | その人ならではの癖（例：ジンはアヤメに話しかけたいが、たいてい見ているだけ） |
| 8 | 日課 | 時間割どおりの場所へ行き、仕事をする。人がいればおしゃべり、いなければぶらぶらする |

基本の一日は「朝は家 → 8〜14 時は仕事場 → 夕方は自由 → 日暮れは酒場 → 夜は家で眠る」。
村人ごとの時間割・口癖・習慣・噂好き度は `seed/village.json` で決まっている。

## 世界のルール（`sim/world.py`）

- 4 時間ごとに腹が減り、疲れる。仕事をすると疲れる。夜は全員家で眠り、薪を 1 本燃やせばよく眠れる。
- 仕事場で働くと、職業ごとの品が手に入る（パン、野菜、魚、肉と薪、薬草と山菜、エールとシチュー、歌って銀貨）。雨や嵐の日は外の仕事の実入りが減る。
- 売り買いは村の相場で行う。売り手は「自分の分（食べ物 2 つ）を残して余っていて、相手をひどく嫌っていなければ」売る。
- 村人が知っているのは、その場で見聞きしたことと、自分の記憶メモだけ。人のセリフはしばらく噂として覚えている。

## 村人が使うツール

ルールでも AI でも、村人は同じツールで世界に働きかける。

| 種類 | ツール |
| --- | --- |
| 行動（1 回で 2 時間が終わる） | `move` 移動 / `say` 話す / `work` 働く / `eat` 食べる / `give` 渡す / `buy` 買う / `sell` 売る / `rest` 休む / `do` 自由な行動 |
| 心の動き（何度でも） | `remember` 記憶メモを書く / `update_impression` 人への印象を変える |

`--ai` のときは、上の基本ルールと各自の習慣が「ふだんの暮らし」としてプロンプトに入り、Claude はそれを下敷きにしつつ状況に応じて自由に判断する。
モデルは `VILLAGE_MODEL`（既定 `claude-opus-5-5`）、考える深さは `VILLAGE_EFFORT`（既定 `low`）で変えられる。

## 村を変える

`seed/village.json` を書き換えて `python3 run.py --reset` すれば、別の村で始められる。
村人ごとに `routine`（時間割）、`lines`（口癖）、`habits`（習慣）、`talk`（話し好き度）、`gossip`（噂好き度）を設定できる。
