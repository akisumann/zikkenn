# 基本ルール（オリジナル2d6システム）

シンプルさと物語の流れを優先した、AI GM 向けの軽量ルール。

## 1. 能力値

PC は 4 つの能力値を持つ。値は **0〜3**。

| 能力値 | 使う場面 |
| --- | --- |
| **肉体** | 力仕事、殴り合い、耐久、走る・登る・泳ぐ |
| **技巧** | 器用さ、射撃、隠密、鍵開け、素早い反応 |
| **知性** | 知識、調査、推理、魔術、記憶 |
| **心** | 意志、交渉、直感、恐怖への抵抗、カリスマ |

作成時は合計 **6 点**を振り分ける（各 0〜3）。

## 2. 技能

キャラクターを表す短い言葉（例：「剣術」「薬草学」「口八丁」「船乗り」）。
作成時に **3 つ**選ぶ。判定内容に技能が当てはまれば **+2**。
どの技能が当てはまるかは GM が判断し、当てはまる理由をプレイヤーが説明してもよい。

## 3. 判定

```
2d6 + 能力値 + 技能(+2) + その他の修正  ≥  目標値 なら成功
```

| 難易度 | 目標値 |
| --- | --- |
| 易しい | 7 |
| 普通 | 9 |
| 難しい | 11 |
| 至難 | 13 |

- **クリティカル**：出目が 6・6。目標値に関係なく成功し、追加の利益がある。
- **ファンブル**：出目が 1・1。目標値に関係なく失敗し、事態が悪化する。
- **代償付き成功**：達成値が目標値に 1〜2 足りないとき、GM は「代償と引き換えの成功」を提案できる（怪我、時間のロス、物を落とす、敵に気づかれる など）。プレイヤーは受け入れるか、ただの失敗にするかを選ぶ。

失敗は「何も起きない」ではなく、**物語が別の方向へ動く**ものとして扱う。

### 対抗判定

両者が判定し、達成値の高い方が勝つ。同値なら現状維持（守る側の勝ち）。

## 4. HP と気力

- **HP** = 10 + 肉体 × 2。0 になると戦闘不能。戦闘不能中にさらにダメージを受けるか、そのまま放置されると死亡の危険がある（GM 判断）。
- **気力** = 3 + 心。以下に使う。
  - **1 点**：判定の直後にダイスを振り直す（1 回の判定につき 1 回まで）。
  - **1 点**：判定の前に宣言して +1。
  - **2 点**：特技を使う（キャラクターシート参照）。

休息（一晩の睡眠など）で HP は 肉体+3、気力は全回復。

## 5. 戦闘

1. **行動順**：各自 2d6 + 技巧。高い順に行動する。敵は GM がまとめて振ってよい。
2. **ラウンド**：各キャラクターは自分の番に「移動＋行動 1 つ」ができる。
3. **攻撃**：`2d6 + 肉体 or 技巧 + 技能` を相手の **回避値** に対して判定する。
   - 回避値 = 7 + 技巧（PC）。敵はデータに記載。
4. **ダメージ**：武器のダメージ − 相手の防護点（最低 0）。クリティカルなら武器ダメージを 2 回振って合計する。

| 武器の例 | ダメージ |
| --- | --- |
| 素手 | 1d3 |
| 短剣・棍棒 | 1d6 |
| 剣・斧・弓 | 1d6+1 |
| 両手武器・銃 | 1d6+3 |

| 防具の例 | 防護点 |
| --- | --- |
| 厚手の服 | 1 |
| 革鎧 | 2 |
| 鎖帷子 | 3 |

戦闘は会話・逃走・降伏で終わってもよい。全滅させることが目的ではない。

## 6. 成長

セッション終了時に **経験点 1〜3** を得る（目的達成・印象的なロールプレイ・大きな失敗から学んだ など）。

| 成長 | 経験点 |
| --- | --- |
| 技能を 1 つ追加 | 3 |
| 特技を 1 つ追加 | 4 |
| 能力値を +1（上限 4） | 6 |
| 最大 HP +2 | 2 |
